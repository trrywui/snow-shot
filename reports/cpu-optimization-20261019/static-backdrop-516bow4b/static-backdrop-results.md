## 静态底图与动态覆盖层分离

继续使用上述硬件和工具链，固定基线为 `f51d700c5`。实验使用独立、无阴影、
不接收输入的原生 `NSPanel` 呈现静态底图；原有透明 Qt 窗口保留选区、放大镜和
工具栏。通过 `SNOW_SHOT_STATIC_BACKDROP=1` 启用，未降低默认帧率。
测试副本使用独立数据目录、关闭全局快捷键和自启动；系统安装版及其配置未修改。

**结论：撤回运行时代码，仅归档结果和补丁。** 固定 API 输入下应用 CPU 有小幅、
重复可见的下降，但单轮真实鼠标测试未确认收益，且仍出现较高峰值。增加原生窗口、
颜色空间和生命周期维护的成本，目前缺少足够的真实交互收益来支持采用。
不能据此宣称已经解决交互时 40%+ CPU，也不能证明所有手动场景均退化。

### 无详细日志的 CPU 测试

按照基线/实验/实验/基线/基线/实验交替运行，每阶段目标 30 次/秒、持续 10 秒。
全部六轮有效，每阶段完成 297–300 次更新。数值为三轮中位数，100% 表示一个
逻辑核心；没有同时编译或进行调用栈采样。

| 指标 | 基线 | 分离版 | 差值 |

| 调整选区：应用 CPU | 47.69% | 44.28% | −3.41 个百分点 |
| 移动选区：应用 RSS | 201.97 MiB | 183.91 MiB | −18.06 MiB |
| 调整选区：应用 RSS | 202.05 MiB | 183.89 MiB | −18.16 MiB |
| 移动选区：WindowServer CPU | 45.98% | 42.49% | −3.49 个百分点 |
| 调整选区：WindowServer CPU | 44.10% | 43.08% | −1.02 个百分点 |

应用 CPU 原始值：移动基线 48.19/49.98/48.18%，实验 46.39/46.09/43.38%；
调整基线 47.69/47.39/47.80%，实验 42.38/44.79/44.28%。
WindowServer 是共享进程；实验中一轮移动阶段达 52.38%，不能仅凭中位数认定
合成器负担稳定降低。RSS 是进程驻留内存，不等于活动监视器内存占用或 GPU 总内存。

该测试通过应用自己的私有 MCP 接口操作已有选区，包含接口和编辑状态维护，
并非真实鼠标悬停或按住拖动，不应与手动操作、原版或 Snipaste 的绝对 CPU 比较。

### 真实鼠标与正确性

用户分别操作基线和分离版：静止、鼠标移动、拖动框选、松开静止、双击复制。
两轮均确认外观、流畅度和复制无异常，独立副本随后正常退出。

采样没有记录鼠标按下/松开的精确时间，两轮截图持续时间分别为约 38.97/30.41 秒，
阶段不能按同一秒数严格对齐，因此不计算手动操作的收益百分比。
基线移动阶段可见约 14–27%、拖动阶段可见约 30–82% 的一秒应用 CPU 样本；
分离版操作期间仍可见约 15–104% 的样本。它们包含阶段转换与不同移动速度，
只能说明这次手动验证未确认稳定降幅，不能将峰值差归因为分离本身。
两者静止后应用 CPU 均基本回到 0%。
