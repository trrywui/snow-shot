本次发布采用已完成本机实测的截图 CPU 精简优化方案：

- macOS 截图交互默认限制为 30 Hz，无需通过启动脚本设置。
- 缓存放大镜的阴影和面板背景，主题、尺寸或缩放变化时重建。
- 鼠标松开和确认操作立即提交最终选区。

两轮手动测试中，精简候选移动鼠标 CPU 中位数约为 23.58% / 24.58%，
拖动框选约为 31.32% / 34.77%，静止约为 0%。100% 表示一个逻辑核心；
手动操作范围和系统状态存在差异，这些数据不代表所有设备上的固定降幅。
放大镜阴影、颜色、跟手和复制已由用户确认正常。

Release 构建、应用签名校验、启动探针、DMG 完整性和 SHA-256 校验通过。
