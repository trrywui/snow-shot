# 30 Hz＋原生放大镜透明度独立验证

从仅限帧提交 b7c03b439 建立 codex/screenshot-30hz-native-opacity，
不包含BGRA和装饰缓存；仅Cocoa使用原生窗口透明度，其它平台保留
QGraphicsOpacityEffect。增加透明度变更、隐藏、复用和换属主测试。

使用原有Release增量构建；本轮为手动真实交互采样，不执行benchmark target。
两版均30 Hz、相同隔离配置、默认GUI线程池、正常放大镜，无paint日志、
无调用栈采样，采样时不编译。正式安装版与配置不变。
CPU为约一秒内进程累计CPU时间差，100%表示一个逻辑核心。
只在测试截图窗口存在时记录指针坐标和按键，辅助区分交互阶段。
手动轨迹不完全一致，不将单轮差值视为精确因果收益。

## 实测结果

有效顺序为候选 opacity30 → 完整优化版 full30，均正常放大镜、30 Hz。
两轮分别记录到一次完整截图开始与结束，持续35.89 / 32.80秒。
用户回复“两轮完成”，未单独描述放大镜、跟手和复制结果；不将窗口结束
事件等同于已验证剪贴板复制成功。截图与系统配置和基线一致，SHA已核验。

| 约一秒有效区间中位数 | 30 Hz＋原生透明度 | 完整优化版 |
| --- | ---: | ---: |
| 移动：应用CPU | 36.92% | 25.50% |
| 框选：应用CPU | 45.22% | 31.50% |
| 静止：应用CPU | 0% | 0% |
| 有效移动/框选/静止区间 | 12/11/8 | 11/9/9 |
| 移动：路程（逻辑px/区间） | 684.64 | 832.51 |
| 框选：路程（逻辑px/区间） | 275.40 | 304.48 |
| 估算选区面积中位数（逻辑px） | 549634 | 448857 |
| 移动：WindowServer CPU | 41.37% | 44.25% |
| 框选：WindowServer CPU | 43.25% | 42.24% |

候选移动比完整优化版慢约18%，框选慢约10%，选区面积约大22%。CPU范围：
候选移动4.91–39.27%、框选38.22–49.94%；完整移动1.97–27.58%、
框选24.56–34.54%。完整优化版移动/框选25.50/31.50，与此前完整版本
23.62/31.96、复核24.09/28.50接近。整轮RSS峰值214.09/213.96 MiB，
包含其它阶段，不用于单独归因内存。

单独原生透明度未达到完整优化版表现；移动更慢仍显示较高CPU，使仅由
移动速度解释差异不充分。但选区、轨迹、系统状态未严格控制，不能认定
精确因果降幅。没有同轮仅限帧对照，不宣称原生透明度完全无收益。

本轮不支持直接采用“30 Hz＋原生透明度”作为等效精简替代。完整优化版
尚有装饰缓存、BGRA及组合效应，无法据此归因给缓存。若继续以少改动为
目标，下一步可以从仅限帧起点单独加入装饰缓存，保留原始透明度和像素
格式，继续逐项检验；本轮没有实施该方案。

测试副本、采样与指针探针均已退出，正式版PID550保持运行。源码工作区
干净，实验在独立分支保存，未合并到其它分支或替换正式安装版。
